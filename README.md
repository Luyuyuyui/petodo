# Petodo · 重事，不忘。

> 一个始终在你桌面边缘的温柔提醒。  
> 一件事若足够重要，就不该被忘记。

**Petodo** 是一个 Windows 桌面待办工具。它不占 Dock，不抢焦点，只安静地待在屏幕边缘——你忙时它隐身为一只小宠，你稍作停留，它便展开今日待办。

**三种形态，一键切换，始终置顶。**

---

## ✨ 它怎么帮你

| 形态 | 做的事 |
| :--- | :--- |
| 🐱 **桌宠** | 一个会动的小家伙——它是桌面上的温柔提醒，不打扰，不消失。 |
| 📋 **Todo** | 极简待办列表，完成项自动置底划线，底部快速输入，右上角显示今日进度。所有数据本地保存，永久可查。 |
| 🕐 **倒数日** | 最近倒数日大数字 + 当前时间 + 秒表，一瞥即知。背景可换成喜欢的风景图，让时间变得有仪式感。 |

**三种形态共享一套数据，一个快捷键（`Ctrl+1/2/3`）即可切换。**

---

## 🖱️ 交互方式


| 形态 | 悬浮图标 | 悬停（400ms 后） | 左键单击 | 右键菜单 |
| --- | --- | --- | --- | --- |
| 🐱 桌宠（默认） | 卡通形象（内置 3 张像素图 / emoji / 上传图片，设置页切换） | 弹跳展开动画 + 功能按钮 | 展开今日 Todo 列表 | 切换形态 / 快速添加任务 / 设置 |
| 📋 Todo | 列表图标 | 右侧 280×340 今日待办卡片（已完成置底划线、底部快速输入、右上角「已完成 X 项」）+ 功能按钮 | 完整 Todo 面板（日历 + 历史） | 切换形态 / 添加任务 / 设置 |
| 🕐 倒数日 | 时钟图标 | 下方 280×200 迷你仪表盘（最近倒数日大数字 + 当前时间 HH:MM:SS + 秒表状态，背景可在设置页换内置风景图或上传图片）+ 功能按钮 | 完整面板（倒数日列表 + 计时器） | 切换形态 / 添加倒数日 / 设置计时器 / 设置 |

### 悬停功能按钮
悬停图标时图标周围出现一圈半透明圆形按钮（28px，悬停变实心）：
- 🔄 切换形态（桌宠 → Todo → 倒数日循环）
- ➕ / 📅 / ⏱ 当前形态的快捷操作（快速添加 / 完整日历 / 添加倒数日 / 设置计时器）
- ⚙️ 打开设置　✕ 退出应用

### 切换方式
1. 悬停点击 　2. 右键菜单「切换形态」　3. 快捷键 `Ctrl+1` / `Ctrl+2` / `Ctrl+3`　4. 托盘菜单



> 离开图标与面板区域 600ms 自动收起，给你充足的时间从容移入面板，不急不躁。

## 🎨 设计风格

- 纯白卡片 + 1px 浅灰边框
- 8px 圆角 + 极淡阴影
- `#3370ff` 作为唯一强调色
- 无毛玻璃、无强渐变、无多余装饰

完成的任务变灰 + 删除线，但不消失——**每一个打勾的瞬间，都是对自己的回响。**

---

## 💾 数据归属你

所有数据存于本地 JSON 文件（`%APPDATA%\petodo\petodo-data.json`）：

- Todo 永久保存（含标签、任务级计时、完成时间）
- 倒数日与计时记录
- 窗口位置与形态偏好

**不上传，不同步，不分析。你的数据只属于你。**

（飞书同步为预留功能，需要时可一键开启。）

## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/Luyuyuyui/petodo.git
cd petodo

# 安装依赖
npm install

# 启动开发模式（Node.js 20+，Windows 10/11）
npm run dev

# 打包 Windows 便携版
npm run package:win
```

## 🗂️ 项目结构

```
electron/
  main.ts          # 窗口管理、悬停状态机、托盘、IPC、持久化
  preload.ts       # IPC 白名单桥接
src/
  icon.tsx         # 悬浮图标（56×56） + 悬停按钮环 + 气泡
  panel.tsx        # 面板窗口（待办 / 倒数日 / 计时器 / 历史 / 设置）
  types.ts         # 数据模型
  lib.ts           # 日期与计时工具
  style.css        # 全局极简样式
```
